# 🎮 steam-idler نسخه‌ی Render — ساعت‌زنی CS2 با تنظیمات env

این نسخه طوری ویرایش شده که **هیچ پسوردی توی کد نباشه** — همه‌چی از **Environment Variables** رندر خونده می‌شه و یه **صفحه‌ی وضعیت** هم رو آدرس سرویس بالا میاد. تأیید ورود هم با **اپ Steam گوشی** انجام می‌شه. ✅

## ⚙️ متغیرهای محیطی (env)

توی رندر برو به: **Web Service → Environment → Environment Variables** و اینا رو اضافه کن:

| متغیر | مثال | توضیح |
|---|---|---|
| `ACCOUNTS` ⭐ | `ddanialb:qrcode` | **بدون پسورد!** به‌جای پسورد کلمه‌ی `qrcode` رو بذار → QR Code رو صفحه میاد و با گوشی اسکن می‌کنی 📱 (روش قدیمی با پسورد هم کار می‌کنه: `user:pass`) |
| `PANEL_USER` ⭐ | `admin` | یوزرنیم **ادمینِ پنل** |
| `PANEL_PASS` ⭐ | `یک-رمز-قوی` | رمز **ادمینِ پنل** — بدون رمز هیچ‌کس به پنل دسترسی نداره 🔒 |
| `PLAYING_GAMES` ⭐ | `730` | بازی‌های پیش‌فرض شروع. `730` = **CS2**. چند بازی: `730,440` (بعداً از داخل پنل هم می‌تونی اضافه/حذف کنی) |
| `REFRESH_TOKENS` | `ddanialb:eyJ...` | اگه استیم ورود رو بلاک کرد، توکن رو از کامپیوتر خونه بده اینجا (پایین‌تر توضیح داده شده 👇) |
| `PROXY` | `http://user:pass@ip:port` | پروکسی برای دور زدن بلاک IP رندر (اختیاری، چندتا با ویرگول) |
| `ONLINE_STATUS` | `1` | وضعیت نمایش: `1` آنلاین، `0` نامرئی (پیش‌فرض ۱) |
| `AFK_MESSAGE` | `Hi!` | جواب خودکار به پیام دوستان (خالی = خاموش) |

## 🎛️ پنل مدیریت

روی آدرس سرویس (`https://your-app.onrender.com`) اول **صفحه‌ی لاگین** میاد — با `PANEL_USER` و `PANEL_PASS` وارد شو. امکانات:

| قابلیت | توضیح |
|---|---|
| ▶⏸ **شروع/توقف فارم** | شروع یا توقف ساعت‌زنی (بات آنلاین می‌مونه) |
| ⏻ **روشن/خاموش بات** | قطع/وصل کامل اکانت از استیم |
| 🔍 **سرچ بازی** | اسم بازی رو بنویس (بدون نیاز به کد) و با یک کلیک اضافه کن — چند بازی همزمان تا سقف ۳۲ تا |
| ⏱ **توقف خودکار** | مثلاً `100 ساعت و 10 دقیقه` — بعدش خودش بات رو خاموش می‌کنه و شمارنده‌ی باقی‌مانده نشون می‌ده |
| 🔄 **ری‌استارت خودکار** | اگه اکانت آفلاین شد، هر ~۲ دقیقه خودش لاگین می‌کنه (با تیک روشن/خاموش می‌شه) |
| ➕ **افزودن اکانت استیم از داخل پنل** | هر کاربر یوزرنیم استیم خودش رو می‌زنه → **QR مخصوص خودش** رو توی پنل می‌بینه → با اپ اسکن می‌کنه → فارم شروع می‌شه 📱 |
| 👥 **کاربر جدید** | ادمین برای هر رفیق یوزر/رمز می‌سازه و بده بهش — خودش لاگین می‌کنه، اکانت خودش رو اضافه می‌کنه، بازی سرچ می‌کنه، فارم می‌کنه |

فلوی دعوت رفیق: **ادمین کاربر می‌سازه ← یوزر/رمز رو می‌ده بهش ← اون لاگین می‌کنه ← از کارت «➕ افزودن اکانت استیم» یوزرنیمش رو می‌زنه ← QR خودش رو اسکن می‌کنه ← تمام!** هر کاربر فقط اکانت خودش و QR خودش رو می‌بینه 🔒

> 🔐 امنیت: بدون لاگین هیچ داده/QR/دکمه‌ای دیده نمی‌شه، ۸ بار رمز اشتباه = IP موقتاً محدود می‌شه، اسم اکانت‌ها همیشه مخفی‌سازی شده (`dd***`) نمایش داده می‌شه و رمز کاربرهای ساخته‌شده هش‌شده ذخیره می‌شه.
> 💾 تنظیمات پنل توی `state.json` ذخیره می‌شه و تا Redeploy بعدی باقی می‌مونه (بعد از Redeploy به پیش‌فرض env برمی‌گرده).

## 🚫 ارور «Steam has blocked this sign in» — چیکار کنم؟

این یعنی استیم **IP دیتاسنتر رندر** رو مشکوک تشخیص داده (چون اکانتت همیشه از ایران لاگین می‌شده). **اکانتت امنه، نگران نباش.** راه‌حل:

### روش ۱ (بهترین و تست‌شده): توکن رو از خونه بگیر 🏠
توکن استیم به IP وابسته نیست؛ پس یه بار رو کامپیوتر خودت لاگین می‌کنی و توکن رو می‌بری رو رندر:

1. این پوشه رو روی کامپیوترت داشته باش + [Node.js LTS](https://nodejs.org) نصب کن
2. توی ترمینال/CMD داخل پوشه:
   ```
   npm install
   ```
3. فایل `accounts.txt` رو باز کن و زیر خط کامنت بنویس: `ddanialb:qrcode`
4. اجرا کن: `node idler.js` → **QR توی ترمینال ظاهر می‌شه** ← با گوشی اسکن کن (اینجا IP خونته و استیم بلاک نمی‌کنه ✅)
5. بعد از لاگین موفق (پیغام `Logged in!`) برنامه رو ببند و فایل **`src/tokens.db`** رو با Notepad باز کن → یه خط JSON می‌بینی که توش `"token":"eyJ..."` هست — اون رشته‌ی طولانی جلوی token رو کپی کن
6. توی رندر env اضافه کن:
   ```
   REFRESH_TOKENS = ddanialb:eyJhbGciOi... (همون رشته‌ی کپی‌شده)
   ```
   (چند اکانت با ویرگول: `user1:token1,user2:token2`)
7. Redeploy کن → این‌بار بدون QR مستقیم `Logged in!` می‌شه 🎉

توکن مثل پسورده — **به کسی نده** و env رو نگه دار تو رندر.

### روش ۲: پروکسی
اگه پروکسی HTTP تمیز (ترجیحاً ایران/رزیدنشل) داری، توی env بذار:
```
PROXY = http://user:pass@ip:port
```
که استیم به‌جای IP رندر، IP پروکسی رو ببینه. پروکسی‌های رایگان معمولاً خودشون بلاکن.

## 📱 ورود بدون پسورد (QR Code) — پیشنهادی

۱. توی env بنویس: `ACCOUNTS=ddanialb:qrcode`
۲. بعد از Deploy، آدرس سرویس رو تو مرورگر باز کن → یه **QR Code** می‌بینی (صفحه هر ۸ ثانیه خودش رفرش می‌شه)
۳. اپ **Steam** گوشیت ← **Steam Guard** 🛡️ ← اسکنر ← کد رو اسکن کن و تأیید بزن
۴. تمام! صفحه خودش به «🎮 در حال فارم» تغییر می‌کنه

- اگه دیر رسیدی اسکن کنی مهم نیست — برنامه **هر ۶۰ ثانیه خودش QR جدید می‌سازه** 🔄
- بعد از اولین تأیید، توکن ذخیره می‌شه و تا وقتی Redeploy نکنی دیگه نیازی به اسکن نیست
- ⚠️ آدرس سرویس رو به کسی نده — هرکس لینک رو داشته باشه QR رو می‌بینه (البته فقط آدمی که اپ استیمِ اکانتِ خودش رو داشته باشه می‌تونه اسکن کنه، ولی باز نگهش دار)

## 🚀 قدم‌به‌قدم (همون چیزی که می‌خواستی)

**۱.** یه ریپو توی گیت‌هاب بساز (Private بهتره، ولی چون پسورد توی کد نیست Public هم مشکلی نداره) و محتویات این پوشه رو پوش کن.

**۲.** توی Render: **New + → Web Service** → ریپوت رو کانکت کن با این تنظیمات:

```
Runtime:        Node
Build Command:  npm install
Start Command:  npm start
Plan:           Free
```

**۳.** قبل از Deploy، از قسمت **Environment** متغیرهای جدول بالا رو اضافه کن.

**۴.** Deploy رو بزن → برو تب **Logs** → بعد از حدود ۱ دقیقه این پیام رو می‌بینی:

```
Please confirm this login request in your Steam Mobile App.
```

**۵.** 📱 اپ **Steam** گوشیت رو باز کن → منوی **Steam Guard** → **تأیید ورود** رو بزن.  
تمام! برنامه می‌ره روی CS2 و ساعت پلی می‌زنه. 🎮

**۶.** آدرس سرویس رو باز کن (`https://your-app.onrender.com`) — صفحه‌ی وضعیت رو می‌بینی:

- 🎮 وضعیت فارم (آنلاین / در حال فارم / مدت سشن)
- ⏱ آپتایم سرویس
- 🎯 بازی‌های در صف فارم
- اسم اکانت به‌صورت مخفی (`ab***`) نشون داده می‌شه — نگران لو رفتن نباش

**۷. (مهم!) جلوگیری از خواب رفتن:**  
رندر رایگان بعد از **۱۵ دقیقه** بی‌ترافیکی می‌خوابه! برو [uptimerobot.com](https://uptimerobot.com) یا [cron-job.org](https://cron-job.org) (رایگان) → یه مانیتور بساز که **هر ۵ دقیقه** آدرس سرویست رو پینگ کنه. تمام، ۲۴/۷ روشن می‌مونه. 😴➡️☀️

## 🔁 لوپ «LoggedInElsewhere» — چیکار کنم؟

اگه تو لاگ مدام `Logged in` → `Lost connection: LoggedInElsewhere` → `Relog` تکرار می‌شه، یعنی **همین اکانت یه جای دیگه هم آنلاینه** و دوتا برنامه همدیگه رو می‌ندازن بیرون:

1. ❌ مطمئن شو `node idler.js` رو **PC خودت بسته شده** (ترمینال باز نمونده باشه — Task Manager رو هم چک کن)
2. ❌ مطمئن شو روی رندر فقط **یک سرویس** فعاله (سرویس‌های تستی/قدیمی رو Suspend یا Delete کن)
3. ✅ Steam کلاینت معمولی رو PC مشکلی نداره و می‌تونه باز بمونه

> نکته: ویژگی **backoff خودکار** به کد اضافه شده — اگه بازم LoggedInElsewhere بخوره، به‌جای جنگ هر ۱۵ ثانیه، هر ۱۰ دقیقه یه بار تلاش می‌کنه (کمتر اسپم، کمتر ریسک محدودیت استیم). وقتی خودت رو PC بازی می‌کنی هم بعد از بستن بازی، طی چند دقیقه خودش برمی‌گرده.

## ⚠️ نکات مهم

- **بعد از هر Redeploy** (پوش کردن تغییر جدید) حافظه‌ی موقت پاک می‌شه → لازمه **یه بار دیگه توی اپ گوشی تأیید کنی**. تا وقتی دیپلوی نکنی با UptimeRobot روشن می‌مونه.
- اگه Steam Guardت روی **ایمیل** باشه (نه اپ)، روی رندر کار نمی‌کنه چون جایی برای تایپ کد نیست → Guard رو توی اپ موبایل فعال کن.
- این روش به سرور بازی وصل نمی‌شه (فقط «در حال بازی» نشون می‌ده) → **VAC ban نداری**؛ ولی به‌خاطر قوانین استیم مسئولیتش با خودته.
- خودت همزمان بازی کنی، idler قطع می‌شه ولی بعدش خودش دوباره وصل می‌شه.
- سقف استیم ۳۲ بازی همزمانه؛ برای CS2 فقط `730` کافیه.

## 📁 تغییرات نسبت به نسخه‌ی اصلی

| فایل | تغییر |
|---|---|
| `idler.js` | خواندن کانفیگ از env + صفحه‌ی وضعیت فارسی روی `$PORT` |
| `src/controller.js` | خواندن اکانت از `ACCOUNTS` env (تقدم نسبت به accounts.txt) + اکسپورت allBots برای صفحه |
| `config.json` | پیش‌فرض CS2 (730) — با env قابل بازنویسیه |
| `render.yaml` | دیپلوی خودکار با Blueprint (اختیاری) |
